# 字段与业务定义

输入编码 UTF-8，允许 BOM。首行必须匹配样例列顺序。记录键和业务组保留原始字符串。`kind` 允许 history, demand, receipt, scenario。说明列 `note` 可以跨行，限制 200 字。

业务字段按 `day`、`quantity`、`lead_time`、`alpha`、`basis_points` 排列。最终值单位见阶段结果。数字接受非负整数、全角数字和完整千分位。空串、短横线、N/A、NULL 与未知为缺值。无关字段用 0 占位。

历史缺行补零需求，正需求间隔从观测起点算起。用精确分数做 Croston 平滑，再乘 1−α/2。补货点为交期需求向上取整。每天先到货、再消耗、最后补到目标，缺货作为失销。回测固定六天，以未满足量占比核对服务要求。

`incoming.csv` 包含四个业务组，第二组提供不同边界，第三组触发业务拒收，第四组需要核对。另含重复表头、冲突记录、重复回放与错误列数。`ready.csv` 含可以签发的两个组。
